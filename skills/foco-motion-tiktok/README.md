# Foco Motion TikTok 1.0

Skill para transformar prints do TikTok Creator Search Insights em roteiros originais e scripts de cenas para vídeos 9:16 do Meu Bebê em Foco.

## Arquivos

- `SKILL.md`: instruções centrais do agente.
- `references/FORMATO_SAIDA.md`: campos obrigatórios e exemplo de JSON.
- `examples/ROTINA_REAL_75S.md`: aplicação com um assunto exibido nos prints do usuário.
- `scripts/validar_roteiro.py`: validação opcional de um arquivo JSON final.

## Instalação

Copie a pasta `foco-motion-tiktok` para o diretório de Skills do seu agente. Em agentes compatíveis com o padrão de pastas de Skill, mantenha o nome `SKILL.md`. Para uso manual no ChatGPT, anexe `SKILL.md` e os prints, e peça para executar a Skill. O agente precisa conseguir ler imagens.

Caminho sugerido no seu projeto: `COMAR DIGITAL/02_SKILLS/foco-motion-tiktok/`.

## Prompt de uso

> Execute a skill foco-motion-tiktok com estes prints. Escolha o tema com maior aderência ao Meu Bebê em Foco e gere roteiro TTS, 13 a 16 cenas com ações 3D e motion design, prompts de cada cena, título, legenda, hashtags e JSON final para automação.

## Ressalvas

Indicadores do print não são previsões de desempenho. Conteúdos de saúde e segurança infantil exigem checagem em fontes confiáveis antes da publicação. Um vídeo acima de um minuto não garante remuneração.
