# Como criar uma skill

1. Escolha a categoria adequada em `skills/`.
2. Crie uma pasta em kebab-case com o nome da skill.
3. Copie a estrutura de `templates/skill/`.
4. Preencha o `SKILL.md` como contrato principal.
5. Adicione referências, scripts e exemplos somente quando agregarem valor.
6. Atualize o catálogo em `docs/catalogo.md`.
