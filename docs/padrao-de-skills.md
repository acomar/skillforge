# Padrão de skills

Cada skill deve ter um `SKILL.md` como arquivo principal.

Estrutura recomendada:

```text
nome-da-skill/
├── SKILL.md
├── referencias/
├── scripts/
└── exemplos/
```

## Convenções

- Pastas e arquivos auxiliares em português quando fizer sentido.
- Nomes de diretórios em kebab-case.
- Instruções objetivas, executáveis e testáveis.
- Referências separadas das instruções principais.
- Scripts devem ser autocontidos e documentados.
